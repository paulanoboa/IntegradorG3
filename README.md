# ProyectoIntegradorG3
Este repositorio contendra el proyecto integrador de la maestria de IA:
Proyecto: Generación de los puntos más peligrosos de Ecuador para detectar zonas de riesgo para alertar a los turistas para que tomen precauciones usando modelos que puedan predecir los meses de mayores incidentes.
Equipo: Grupo3: Harold Rodrigo Angulo Arellano, Paula Elizabeth Noboa Ramírez


Se levanta la información de definciión y planificación del proyecto Integrador:

Descripción breve del proyecto: El proyecto desarrolla un sistema de inteligencia artificial que analiza registros históricos de incidentes en Ecuador para identificar y mapear zonas de mayor concentración delictiva mediante K-Means, y predice los meses con mayor probabilidad de ocurrencia de incidentes usando modelos de Random Forest y XGBoost.
